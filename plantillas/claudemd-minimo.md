# Proyecto

Qué es, en una frase.

## Comandos

- Desarrollo: `npm run dev`
- Pruebas: `npm test`
- Comprobación previa a entregar: `npm run check`

## Reglas

- Ejecuta `npm run check` antes de decir que algo está terminado.
- No confirmes ni subas cambios a git salvo que te lo pida.
- Los cambios de esquema de base de datos van siempre con su migración.
